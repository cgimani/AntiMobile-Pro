# ⚡ وب‌اپلیکیشن هوشمند AntiMobile Pro (v3.1.0)

یک کلاینت وب و PWA فوق‌العاده مدرن، سبک، مینیمال و تمام‌صفحه با تم تاریک عمیق (**Dark OLED Theme**)، الهام‌گرفته از تجربه کاربری و قابلیت‌های بومی **Google Antigravity (AGY)**، اتصال مستقیم و استریم لحظه‌ای باینری رسمی CLI، بدون نیاز به پسورد و موانع اضافی، بهینه‌سازی‌شده برای صفحه‌نمایش‌های لمسی گوشی (Termux)، تبلت و دسکتاپ با پشتیبانی ۱۰۰٪ از زبان فارسی و راست‌به‌چپ (RTL).

---

## 🌟 ویژگی‌های برجسته و قابلیت‌های پیاده‌سازی‌شده

### 🔐 ۱. سیستم یکپارچه احراز هویت، ورود و خروج (Authentication & Session Security)
- **ورود و خروج امن (Login / Logout):** حفاظت کامل از تمامی اندپوینت‌های API و ارتباطات وب‌سوکت با سیستم نشست امن و توکن رمزنگاری‌شده.
- **اطلاعات ورود پیش‌فرض:**
  - **نام کاربری:** `admin`
  - **رمز عبور:** `antigravity`
- **پنل کاربری در منو (Drawer):** نمایش آواتار اختصاصی، وضعیت فعال بودن و دکمه خروج مستقیم.
- **قابلیت تغییر رمز عبور:** امکان تغییر آنی رمز عبور و نام کاربری از طریق پنجره اختصاصی تنظیمات.
- **قابلیت تنظیم از محیط:** پشتیبانی از متغیرهای سیستمی `ANTI_USERNAME` و `ANTI_PASSWORD`.

### 🧠 ۲. شفافیت تفکر عمیق ایجنت (Agent Thinking Process)
- **نمایش فرایند تفکر لحظه‌ای:** در حین پردازش هر پیام، جعبه شیشه‌ای نئونی تفکر با انیمیشن ملایم (Pulse Glow) و تایمر ثانیه‌شمار زنده (`0.0s`) فعال می‌شود.
- **استخراج کامل تفکرات:** تفکرات درونی ایجنت هوشمند به همراه تعداد توکن‌های تفکر (`thinking_tokens`) و مدت زمان استدلال در قالب یک کارت بازشونده (Accordion) نمایش داده می‌شود.
- **ماندگاری در سابقه:** تفکرات ایجنت همراه با پیام‌ها در دیتابیس لوکال ذخیره شده و در بازبینی‌های بعدی نیز در دسترس است.

### ⚙️ ۳. گزارش گام‌به‌گام عملیات و ابزارهای اجرا شده (Actions & Steps)
- نمایش زنده تمامی ابزارهای فراخوانی‌شده توسط ایجنت در طول کار:
  - 💻 **اجرای دستورات ترمینال (`run_command`):** همراه با خلاصه دستور، وضعیت، مینی‌ترمینال تیره، هایلایت خروجی، دکمه کپی و دکمه متوقف‌سازی (Kill).
  - 📄 **خواندن و بررسی فایل‌ها (`read_file` / `view_file`):** نمایش نام فایل، مسیر و قابلیت باز شدن مستقیم در ویرایشگر فایل.
  - ✏️ **ویرایش و ایجاد فایل‌ها (`write_file` / `edit_file`):** نمایش فایل‌های اصلاح‌شده با برچسب اختصاصی.
  - 🔍 **جستجو در وب و دایرکتوری (`search_web` / `grep_search`).**
  - 🤖 **ساب‌ایجنت‌ها (`invoke_subagent`).**

### ✨ ۴. نوار کنترل سریع ویژگی‌های انتیگرویتی (Quick Control Pills)
- **انتخاب‌گر شناور مدل (Model Switcher):** با یک لمس، پنجره زیرین (Bottom Sheet) باز شده و امکان تعویض آنی میان مدل‌های رسمی گوگل، کلود و مدل‌های متن‌باز فراهم می‌شود.
- **تنظیم میزان تلاش استدلال (Reasoning Effort):** قابلیت تنظیم سریع سطح تفکر میان `کم (low)`، `متوسط (medium)`، `زیاد (high)` و `حداکثر (max)`.
- **حالت اجرای ایجنت (Execution Mode):** سوییچ سریع میان حالت‌های `خودکار (auto)`، `طرح‌ریزی مرحله‌به‌مرحله (/plan)` و `نیاز به تایید (request-review)`.
- **پایش زنده تاخیر شبکه (Ping Latency):** نمایشگر ثانیه‌ای پینگ و کیفیت اتصال.

### 🎙️ ۵. نوار ورودی هوشمند با اتوکامپلیت و تایپ صوتی (Smart Input Dock)
- **منوی هوشمند دستورات اسلش (Slash Autocomplete):** دسترسی سریع به `/goal`، `/plan`، `/boost`، `/compact`، `/schedule`، `/browser`، `/model`، `/effort`، `/mode`، `/restart` و `/help`.
- **منوی ارجاع فایل‌ها (@ Mentions Popover):** فراخوانی سریع فایل‌ها و پوشه‌های پروژه با نوشتن `@`.
- **تایپ صوتی هوشمند (Voice Dictation):** امکان ضبط و تبدیل گفتار به متن از طریق Web Speech API.
- **دکمه لغو و توقف سریع (Stop Button):** توقف آنی پردازش و اجرای دستورات در حال اجرا.

## 🚀 نصب، به‌روزرسانی و مدیریت هوشمند (Smart Installer & Manager)

اسکریپت هوشمند `install.sh` به صورت خودکار تشخیص می‌دهد که برنامه روی سیستم یا گوشی شما نصب شده است یا خیر. در صورت نصب بودن، یک منوی تعاملی برای **به‌روزرسانی (Update)**، **اجرا (Start)**، **توقف (Stop)**، **تعمیر/نصب مجدد (Reinstall)** یا **حذف کامل (Uninstall)** در اختیارتان می‌گذارد.

### روش ۱: نصب مستقیم از گیت‌هاب (روی ترموکس اندروید یا سیستم جدید)
```bash
curl -fsSL https://raw.githubusercontent.com/cgimani/AntiMobile-Pro/main/install.sh | bash
```

### روش ۲: منوی تعاملی مدیریت یا به‌روزرسانی
```bash
./install.sh
```

### روش ۳: دستورات مستقیم پرچم‌های خط فرمان
```bash
# به‌روزرسانی مستقیم به آخرین نسخه بدون پرسش اضافه
./install.sh --update

# حذف کامل برنامه از سیستم
./install.sh --uninstall

# مشاهده نسخه
./install.sh --version
```

پس از نصب، می‌توانید با دستورات زیر در ترمینال سرور را کنترل کنید:

```bash

antimobile
# یا
agy-web
# یا
./start.sh

# متوقف کردن سرور
./stop.sh
```
